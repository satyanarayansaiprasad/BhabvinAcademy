# Bhavin Academy: The Dynamic Professional Edition

A high-fidelity, cinematic learning platform built for the modern professional.

## 🚀 Features
- **Cinematic Experience**: Immersive, fluid UI with premium animations and glassmorphism.
- **Dynamic Curriculum**: Advanced course management for instructors and students.
- **Mastery Pillars**: Interactive, high-energy marquees highlighting core skill areas.
- **Premium Admin Panel**: Complete control over platform configuration, media, and course content.
- **Responsive Design**: Flawless experience on every device, from mobile to ultra-wide displays.

## 🛠️ Tech Stack
- **Frontend**: React, Framer Motion, Tailwind CSS, Shadcn UI.
- **Backend**: Node.js, Express, MongoDB.
- **Cloud**: Cloudinary for media storage.

## 📦 Getting Started

### Prerequisites
- Node.js & npm
- MongoDB URI
- Cloudinary Account
- JWT Secret

### Installation
1. Clone the repository.
2. Install dependencies:
   ```bash
   # Server
   cd server
   npm install
   
   # Client
   cd client
   npm install
   ```
3. Set up environment variables in `.env` files for both client and server.
4. Run the development environment:
   ```bash
   # Server
   npm run dev
   
   # Client
   npm run dev
   ```
